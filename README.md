# Ambar – Madrid Retail Mapping

A shared Next.js map backed by Supabase and prepared for Netlify.

## Local development

1. Copy `.env.example` to `.env.local` and fill in the Supabase values.
2. Run `pnpm install`.
3. Run `pnpm dev`.

For the complete deployment procedure, see `SETUP_NETLIFY_SUPABASE.md`.
